# Begotten — данные для NewRecruit

Домашняя игровая система «Begotten» (настольный варгейм) в формате BSData
для сборки ростеров через [NewRecruit](https://www.newrecruit.eu/).

## Файлы

- `Vrata.gst` — игровая система (характеристики, профили оружия, очки)
- `Orden_Privratnikov.cat` — фракция «Орден Привратников»
- `Deti_Satany.cat` — фракция «Дети Сатаны»

## Как подключить игру в NewRecruit

1. Открой https://www.newrecruit.eu/
2. «Add more games» → «Add from GitHub»
3. Введи: `ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ` (замените на адрес этого репозитория)
4. Выбери «Latest Commit (Head)» → «Add»
5. Собирай ростер фракциями «Орден Привратников» или «Дети Сатаны»
